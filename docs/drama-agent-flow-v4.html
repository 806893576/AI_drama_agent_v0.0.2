AI短剧制作方案生成智能体流程图 V4

V4 将 LangGraph 落地所需的条件边显式化：安全、质量、一致性、终验均输出结构化 gate 结果；所有失败分支统一进入 Repair Planner，再由 Producer Router 根据 RepairPlan 做局部返工。

Producer Router：只做阶段推进、条件路由、返工限次、人机确认和最终验收。
Repair Planner：统一接收失败报告，输出 target_node、scope、keep_unchanged 和修复指令。
安全分级：输入、剧本、镜头/视听、视觉 Prompt、最终汇总分层审核。
资产管理：角色、场景、道具、声音、镜头和 Prompt 采用稳定 ID 与版本关系。
状态中心：Graph State 存轻量引用，Artifact Store 存长文本，Asset Registry 存资产关系。
V4 修改点：补齐输入安全、镜头/视听安全、Prompt 安全、最终验收的显式条件门；移除 Prompt 风险绕回镜头/视听审核的歧义；终验不通过也进入统一返工闭环；所有条件边都可直接映射为 LangGraph 的结构化路由函数。
